# Homebrew tap for Osy#

```sh
brew install osysharp/osy/osy
brew upgrade osy
```

Installs `osy` and `osyrin`, the Osy# toolchain, from the releases on [osysharp/cli](https://github.com/osysharp/cli/releases).
The formula is generated by the toolchain's release and pinned to each archive's SHA-256; do not edit it by hand.
